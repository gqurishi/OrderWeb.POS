# Toshiba B-FV4D Phase 8 — TPCL module

## Implemented v1 scope

`ToshibaTpclModule` is a dedicated command generator for the 203-dpi Toshiba B-FV4D-GS14. It has no dependency on the receipt-printer or ESC/POS builder.

It currently generates:

- Toshiba-framed commands (`ESC`, command bytes, `LF`, `NUL`)
- media pitch, printable width and label length in 0.1 mm units
- horizontal and vertical offsets
- print darkness and speed
- resident-font fields with multiple sizes
- deterministic wrapping for item name, modifiers and order context
- quantity and local preparation time
- copy count and batch issue in tear-off mode
- the documented `WB` status query

`ToshibaRawTcpTransport` sends the generated bytes to the configured printer endpoint and can return the raw status response. Status bytes are intentionally not interpreted until response samples from the purchased printer have been captured and checked against its firmware documentation.

## Safety and validation

Version one rejects invalid dimensions, widths above 108 mm, invalid speed/darkness/copy ranges, content overflow, unsupported command delimiters, and non-ASCII text. All dynamic label text is normalised before it reaches a TPCL command.

The initial certified path is gap-based die-cut direct-thermal media in tear-off mode. Black-mark, continuous stock, cutter, rotation, raster images, barcodes, QR codes and downloaded/printer-stored assets are explicitly deferred. They must not be enabled by silently approximating another printer language.

## Hardware acceptance still required

Before production, compare captured bytes with the B-FV4 external-interface specification, print the golden 60 × 40 mm test set on the real B-FV4D, calibrate the gap sensor, verify offsets/darkness/speed, test power/network interruption, and capture `WB` replies for ready, cover-open, paper-out and error states.
